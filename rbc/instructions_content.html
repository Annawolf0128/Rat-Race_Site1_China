你将与其他 {{ other_players }} 名玩家一起进行小组游戏。游戏共 {{ num_rounds }} 轮，每一轮的规则都相同。

每一轮，每位参与者选择一个 0 到 100 之间的整数。

所有人提交数字后，系统会计算小组中位数。

小组中位数是 {{ n }} 个所选数字中位于中间的那个值。

例如，若所选数字为 10、30、45、60、80，则小组中位数为 45。

如果你的数字等于中位数或高于中位数，你无需支付罚金。

如果你的数字严格低于中位数，你需支付 {{ L }} 的罚金。罚金是固定的：略低于中位数和远低于中位数支付的罚金相同。

你每轮的收益

你的收益 = {{ E }} − 成本 − 罚金（若低于中位数），其中：

  • 成本 =（你的数字）² ÷ {{ K }}。数字越大成本越高。在选择页面上，系统会实时计算并显示你所选数字的成本。你的成本只取决于你自己选择的数字，与其他人的选择无关。
  • 罚金 {{ L }} 仅当你的数字严格低于当轮小组中位数时才需支付。
每轮结束后的反馈

每轮结束后，你将看到当轮的小组中位数和你的收益。你不会看到其他参与者的选择。

报酬

实验结束时，系统将随机抽取一轮，你将获得该轮的收益，外加固定出场费 ¥15。点数与人民币的兑换比例为 2:1：例如 1 点相当于 ¥0.50。
